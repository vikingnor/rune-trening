RUNES TRENING - PERSONLIG PWA

Innhold:
- Tirsdag, torsdag og søndag-program
- Bilder/tegninger for hver øvelse
- Registrering av kg og repetisjoner per sett
- Tredemølle-minutter
- Kommentar til økten
- Historikk
- Enkel fremgangsgraf
- Lokal lagring i nettleseren
- Offline-støtte når appen er installert som PWA

TEST PÅ PC:
1. Pakk ut ZIP-filen.
2. Åpne kommandolinje i mappen.
3. Kjør: python -m http.server 8080
4. Åpne http://localhost:8080 i nettleseren.

PÅ MOBIL:
For å installere appen som et vanlig app-ikon må mappen ligge på en HTTPS-nettside.
En enkel løsning er GitHub Pages eller Netlify Drop. Når den er publisert åpner du siden i Chrome og velger Installer / Legg til på startskjermen.

DATA:
Treningsdata lagres lokalt i nettleseren på enheten. Sletter du nettleserdata, forsvinner historikken i denne første versjonen.
